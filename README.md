# Cyber_Toolkit

This toolkit include some basic cyber security related tools such as : file integrity checker , log analyzer , password strength checker and Port scanner

## Overview

The Password Strength Checker is a Python-based command-line application that evaluates the strength of a password based on multiple security criteria. It helps users create stronger passwords by identifying weaknesses and providing a strength score along with improvement suggestions.
This project was developed to understand password security principles and common authentication best practices.

## Features 
Checks minimum password length
- Detects uppercase and lowercase letters
- Calculates an overall password strength score
- Tells you if the password is weak or strong

## Technologies Used

- Python
- Regular Expressions (Regex)

# File Integrity Checker

## Overview

The File Integrity Checker is a Python-based tool that verifies whether a file has been modified by comparing its cryptographic hash value with a previously generated hash.

This project demonstrates one of the fundamental techniques used in cybersecurity to detect unauthorized file modifications.

## Features

- Generate SHA-256 hash of files
- Store file hash securely
- Verify file integrity
- Detect modified or tampered files
- Display integrity verification results

## Technologies Used

- Python
- hashlib

# Port Scanner

## Overview

The Port Scanner is a Python-based network scanning tool that identifies open ports on a target host. Open ports indicate running network services, making port scanning one of the first steps in network reconnaissance and security assessment.

This project was built to understand basic networking concepts and how security professionals discover exposed services.

## Features

- Scan a target IP address
- Detect open TCP ports
- Display scan results
- Simple command-line interface

## Technologies Used

- Python
- socket module

# Log Analyzer

## Overview

The Log Analyzer is a Python application that reads and analyzes log files to identify suspicious events and unusual patterns. It demonstrates how security analysts examine logs to detect potential attacks and system anomalies.

This project provides an introduction to Security Operations Center (SOC) workflows and defensive cybersecurity.

## Features

- Read log files
- Detect failed login attempts
- Count repeated events
- Identify suspicious activities
- Generate summary reports

## Technologies Used
- Python
